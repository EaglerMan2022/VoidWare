# GBA Files

Place legally obtained `.gba` ROM files in this folder.

- Suggested format: `games/gba/gbafiles/your-game.gba`
- ROM files are not uploaded by this repository
- Only add games you created or have permission to use

This folder may be used for future built-in ROM selection. The GBA emulator also supports choosing a local ROM through the Browse button on `games/gba/index.html`.
